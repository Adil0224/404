# Ақниет емханасына жазылу сайты

Бұл репозиторийде GitHub Pages-тағы статикалық сайт және Express/PostgreSQL негізіндегі backend бастапқы қаңқасы бар.

## Қазіргі кезеңдер

- Frontend: HTML, CSS және JavaScript. GitHub Pages сайтты көрсетеді.
- Backend: `server/` ішінде Express API қаңқасы.
- Дерекқор: `server/db/schema.sql` кестелерді, `server/db/seed.sql` оқу жобасының мамандарын, филиалдарын, бағаларын және жұмыс кестесін енгізеді.
- API денсаулығы: `GET /api/health` сервер мен PostgreSQL қосылымын тексереді.

## Backend-ті жергілікті іске қосу

1. Node.js 20 немесе одан жоғары нұсқасын орнатыңыз.
2. PostgreSQL дерекқорын жасаңыз.
3. `server` бумасына кіріп, тәуелділіктерді орнатыңыз: `npm install`.
4. `.env.example` файлын `.env` деп көшіріп, `DATABASE_URL` мәнін өз PostgreSQL қосылымыңызбен толтырыңыз.
5. Схеманы және мысал деректерді кезекпен орындаңыз:

   ```sh
   psql "$DATABASE_URL" -f db/schema.sql
   psql "$DATABASE_URL" -f db/seed.sql
   ```

6. API серверін қосыңыз: `npm run dev`.
7. `http://localhost:3000/api/health` адресін ашыңыз.

Windows PowerShell-де схема командаларын орындағанда `$DATABASE_URL` орнына `.env` ішіндегі қосылым жолын тікелей беруге болады.

## Қауіпсіздік ескертпесі

`.env` файлы Git-ке жіберілмейді. Репозиторийдегі үлгі дәрігерлер мен бағалар оқу жобасына арналған. Бұл backend қаңқасында тіркелу, кіру, қабылдау API-лері әлі жүзеге асырылмаған; келесі кезеңдерде авторизация, валидация және API функцияларын қосамыз. Нақты медициналық деректерді бұл демо сайтқа енгізбеңіз.
